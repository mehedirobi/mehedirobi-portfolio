## Built with

React 18, JavaScript, Vite, Tailwind CSS, Framer Motion, and React Icons.

## Run locally

```bash
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```

Run the linter:

```bash
npm run lint
```
